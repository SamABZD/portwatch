retouched or populated with invented records. Original artifacts remain ignored.

Open-Meteo and Copernicus Climate Change Service / ERA5 under applicable CC BY 4.0 terms.
See [source attribution](../SOURCE_AUDIT.md) and [weather credits](../CONTEXT.md#attribution-and-references).
